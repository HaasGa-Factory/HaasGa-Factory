## Projets

### ⚡ WoL Manager

[WoL Manager](https://github.com/HaasGa-Factory/WOL-Manager) est un gestionnaire Wake-on-LAN open source pour Linux et Debian. Il permet de réveiller, vérifier et orchestrer des machines dans un homelab ou un réseau professionnel, avec groupes, dépendances, relais sécurisés et intégration UPS NUT.

### 🛠️ 16motion pour profilé 3030

[16motion pour profilé aluminium 3030](https://github.com/HaasGa-Factory/16motion-for-3030) est une adaptation mesurée et imprimable en 3D d'un chariot coulissant. Le projet fournit des modèles FreeCAD, des STL, des vues d'assemblage et une configuration adaptée à un profilé 3030.
